# Requerimientos Funcionales y No Funcionales

## Requerimientos Funcionales (Req F)
* **Req F1:** El sistema debe permitir al usuario buscar y filtrar proyectos y capacidades I+D mediante categorías rápidas.
* **Req F2:** El sistema debe mostrar una vista de detalle por cada proyecto, incluyendo título, imagen, descripción, año, estado e integrantes.
* **Req F3:** El sistema debe permitir la navegación cruzada, mostrando las relaciones directas entre un proyecto y sus integrantes vinculados.
* **Req F4:** El sistema debe simular un flujo de contacto institucional al presionar el botón de colaboración.

## Requerimientos No Funcionales (Req NF)
* **Req NF1 (Plataforma):** La aplicación debe estar desarrollada en Kotlin nativo y optimizada para dispositivos móviles Android.
* **Req NF2 (Usabilidad):** La interfaz gráfica debe priorizar la legibilidad, con flujos de navegación que no superen los 3 niveles de profundidad (Inicio > Listado > Detalle).
* **Req NF3 (Privacidad y Datos):** El MVP debe operar exclusivamente con datos ficticios, sintéticos, públicos o anonimizados, sin conexión a bases de datos productivas.
